# ProxiSpeak 🎧

**ProxiSpeak — Spatial Audio Prototype**

## About the Project
ProxiSpeak explores how sound can change based on the distance between virtual avatars. This prototype is the first step toward developing a spatial audio experience for ProxiSpeak.

## Current Features
- Play generated audio tones.
- Stop audio playback.
- Adjust simulated avatar distance using a slider.
- Change relative audio volume based on distance.
- Display the current audio status.
- Responsive dark-themed interface.

## Technologies Used
- HTML
- CSS
- JavaScript
- Web Audio API

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Click **Play sound** to start the audio.
5. Adjust the distance slider to experiment with volume changes.
6. Click **Stop** to stop playback.

## Current Limitations
- Avatar distance is simulated using a slider.
- Audio is generated locally in the browser.
- Real avatar positioning and live spatial audio are not implemented yet.
- No microphone or network connection is required for this prototype.

## Future Improvements
- Implement 3D positional audio.
- Connect audio positioning to avatar coordinates.
- Explore real-time proximity-based communication.
- Integrate the audio module with the main ProxiSpeak application.
